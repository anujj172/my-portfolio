**GitHub:** https://github.com/anujj172/my-portfolio

## Бүтээлч санаа

Портфолиог банкны машин (ATM) хэлбэрээр хийсэн. Зочин эхлээд картаа машинд оруулж, PIN кодоо цохиод, дэлгэцийн хажуугийн товч эсвэл дэлгэц дээрх бичгээр цэс сонгоно. Хэсэг бүр банкны үйлчилгээтэй утгаараа таарна:

| Банкны үйлчилгээ | Портфолиогийн хэсэг |
|---|---|
| Танилцуулга | Миний тухай, боловсрол, хувийн ур чадвар |
| Үлдэгдэл | Ур чадвар |
| Түүх (гүйлгээний түүх) | Ажлын туршлага |
| Картууд | Бүтээлүүд (зураг, тайлбар, холбоос) |
| Шилжүүлэг | Холбоо барих |
| Баримт | CV.pdf татах (баримт хэвлэгдэж гарна) |
| Сайтын тухай | Санаа, ашигласан технологи |

Нэмэлт болон нуугдмал боломжууд:
- Карт оруулах хөдөлгөөнтэй, PIN-ийн цэгүүд бөглөгдөнө. Зочдод зориулсан PIN дэлгэц дээр бичигдсэн байна.
- 3 удаа буруу PIN оруулбал "Карт залгигдлаа" гэсэн  мессеж гарч, карт буцаж ирнэ (easter egg).
- "Баримт" сонговол машины баримтын нүхнээс жинхэнэ баримт шиг CV гарч ирнэ.
- Гар (Тийм, Засах, Болих), хажуугийн 8 товч, компьютерийн гар (тоо, Enter, Backspace, Esc) бүгд ажиллана.
- "ANUJIN ATM" нь зохиомол нэр. Жинхэнэ банкны нэр, лого, карт, PIN мэдээлэл ашиглаагүй.

## Хийгдсэн зүйлс

- Танилцуулга, Миний тухай (боловсролын мэдээлэлтэй), Бүтээлүүд (3 бүтээл, зураг, тайлбар, холбоостой), Холбоо барих
- Гар утас болон компьютер дээр ажиллана (responsive)
- Бүх мэдээлэл `data.js`-д тусдаа хадгалагддаг тул код өөрчлөхгүйгээр агуулгыг засна

## Ашигласан технологи

HTML, CSS (vanilla), JavaScript, Vite, Vercel. Бэлэн загвар, UI сан, сайт бүтээгч ашиглаагүй.

## Эх сурвалж

- Дүрс: системийн emoji
- Фонт: хэрэглэгчийн системийн фонт (system-ui, monospace)
- Бүтээлүүдийн зураг: өөрийн төслүүдийн дэлгэцийн зураг
- Кодыг бичихэд AI хэрэгсэл (Claude) ашигласан.

## Ажиллуулах

    npm install
    npm run dev

Дараа нь http://localhost:5173 хаягаар нээнэ.

## Файлын бүтэц

- `index.html` · ATM-ийн бүтэц (дэлгэц, товч, карт, баримтын нүх)
- `src/data.js` · намтар, ур чадвар, бүтээлүүдийн мэдээлэл
- `src/main.js` · ATM-ийн төлөв (карт → PIN → цэс → хуудас), товч, гарны удирдлага
- `src/style.css` · бүх загвар
- `public/images/` · бүтээлийн зургууд
- `public/CV.pdf` · "Баримт" хэсгээс татагдах CV
