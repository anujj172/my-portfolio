**GitHub:** https://github.com/anujj172/my-portfolio

## Бүтээлч санаа

Портфолио нь компьютерын үйлдлийн системтэй төстэй байдлаар ажиллана. Дэлгэц дээрх дүрсүүдээр дамжуулан миний тухай, ур чадвар, туршлага, бүтээлүүд болон холбоо барих мэдээллийг үзэх боломжтой. Дүрс дээр дарахад тухайн мэдээлэл тусдаа цонхонд нээгдэх бөгөөд цонхыг чирэх, жижигрүүлэх, томруулах, хаах боломжтой. Харин бүтээлүүд хэсэгт төсөл бүр тусдаа хавтас хэлбэрээр байрлана.

Нэмэлт болон нуугдмал боломжууд:
- Эхлэх цэс: Портфолиогийн үндсэн хэсгүүд рүү хурдан шилжих боломжтой.
- Taskbar: Дэлгэцийн доод хэсэгт нээлттэй цонхнууд болон бодит цаг харагдана.
- Цонхны удирдлага: Цонх бүрийг жижигрүүлэх, томруулах, хаах товчтой байна.
- Тохиргоо: Хэрэглэгч ханын зургаа өөрчлөх боломжтой бөгөөд сонгосон зураг хөтөчид хадгалагдаж, дараа дахин ороход хэвээр байна.
- "Хогийн сав" ажилладаг: "Хоосолох" дарахад нууц цэнхэр дэлгэц (easter egg)

## Хийгдсэн зүйлс

- Танилцуулга, Миний тухай (боловсролын мэдээлэлтэй), Бүтээлүүд (3 бүтээл, зураг, тайлбар, холбоостой), Холбоо барих
- Гар утас болон компьютер дээр ажиллана (responsive)
- Цонх чирэх нь хулгана болон хуруугаар ажиллана

## Ашигласан технологи

HTML, CSS (vanilla), JavaScript, Vite, Vercel. Бэлэн загвар, UI сан, сайт бүтээгч ашиглаагүй.

## Эх сурвалж

- Дүрс: системийн emoji
- Фонт: хэрэглэгчийн системийн фонт (system-ui, monospace)
- Бүтээлүүдийн зураг: өөрийн төслүүдийн дэлгэцийн зураг
- Кодыг бичихэд AI хэрэгсэл (Claude) ашигласан.

## Ажиллуулах

    npm install
    npm run dev

Дараа нь http://localhost:5173 хаягаар нээнэ.

## Файлын бүтэц

- `src/data.js` · намтар, ур чадвар, бүтээлүүдийн мэдээлэл
- `src/main.js` · аппууд, цонхны систем (нээх, чирэх, жижигрүүлэх), start цэс
- `src/style.css` · бүх загвар
- `public/images/` · бүтээлийн зургууд
